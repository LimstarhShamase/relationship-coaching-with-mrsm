Relationship Building with Mrs M

A responsive, bilingual (English / isiZulu) website built for Thembeka Mkhunu (Mrs M) — Relationship Coach, Qualified Educator, Psychologist (BA (Hons) & Masters in Psychology), and Public Speaker based in Pietermaritzburg, KwaZulu-Natal.

Live Website: https://limstarhshamase.github.io/relationship-building-with-mrsm/ (Update once GitHub Pages is active)

✨ Key Features

Bilingual Experience (EN | isiZulu): Instant language switcher in the top navigation bar that translates page sections, service pillars, interactive check-in prompts, and pre-filled WhatsApp messages into natural KZN isiZulu, persisting user preference via localStorage.

30-Second Relationship Check-In: An interactive 3-step self-reflection tool allowing visitors to select who the session is for, identify their focus area, adjust an urgency slider, receive tailored guidance, and send their check-in summary directly to Mrs M on WhatsApp.

Three Pillars of Support: Clear breakdown of services across Couples & Marriage, Workshops & Growth, and Personal & Intimacy Coaching with direct WhatsApp inquiry triggers.

Moments & Community Gallery: Responsive showcase of radio appearances, fireside dialogues, and couples workshops with a full-screen lightbox viewer and graceful fallback placeholders.

Client Reviews & Mobile Quick-Action Bar: Swipeable Google review highlights and a sticky mobile bottom bar for one-tap calling or WhatsApp messaging (084 416 2803).

🛠️ Tech Stack

Markup & Logic: Semantic HTML5 & Vanilla JavaScript (ES6+)

Styling: Tailwind CSS (via CDN) with a custom warm palette (Cream, Terracotta, Forest Green, and Ochre)

Typography: Google Fonts — Playfair Display & Plus Jakarta Sans

Hosting: Static deployment via GitHub Pages / Cloudflare Pages (zero build step required)

🚀 Deployment (GitHub Pages)

Push index.html, README.md, and all 5 .jpg assets to the main branch root.

Open the repository on GitHub and navigate to Settings → Pages.

Under Build and deployment, set Source to Deploy from a branch.

Select branch main and folder / (root), then click Save.

Wait ~60 seconds for the live HTTPS URL to publish.
